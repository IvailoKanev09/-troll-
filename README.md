# НВО „Учи се, ама друг път“

Най-добрата (и най-нервиращата) интерактивна подготовка за Националното външно оценяване след 7.клас в галактиката!

# За проекта

„Успех на НВО“ е хумористична уеб пародийна игра/платформа за подготовка за НВО (Национално външно оценяване) по Математика и Български език и литература (БЕЛ). Проектът съчетава истински тренировъчни задачи с пълен набор от „трол“ механики: гневящ се виртуален учител (Чичко Професор), бягащ плейър с неумолима чалга музика, параноична система против преписване и излизане от фокус, както и дяволити капчи от ада.

# Основни функционалности:
📖 Предмети и Модули:

Математика и БЕЛ.
Модул 1: Комбинация от затворени (с избираем отговор + ТОТО бутон) и отворени задачи с времеви лимит.
Модул 2: Интензивни отворени задачи с по-дълъг времеви лимит (10 минути).

😡 Нерв-метър (Rage Bar):
Натрупва точки на ярост при грешни отговори или опити за излизане от пътя. При 100% запълване... е, Чичко Професор милосърдно нулира бара, но ти се смее от сърце.

🎵 Бягащ Чалга Плейър:
При грешен отговор се задейства специален музикален режим. Плейърът започва да бяга от мишката ви по екрана и няма да спре гръмката чалга музика, докато не го хванете и укротите с клик!

🛡️ Параноична Анти-чийт Система:
Следи за превключване на табове (visibilitychange), губене на фокус на прозореца (blur) или напускане на цял екран (fullscreenchange), като наказва нарушителите с отнемане на точки.
Блокира забранени клавишни комбинации (DevTools, F11, Esc, Alt+Tab).

🤖 Капчи от Ада:

Преди да продължите към следващия въпрос, трябва да докажете, че не сте робот чрез:
Разпознаване на архаизми (напр. дерибей, айдук, чеверме).
Маркиране на житейски ситуации и мемета в сет от плочки.
Математически задачи-капани.
Аудио капчи със звънене на сигнали.

✍️ Вреден Автокоректор (Typo Injector):

Докато пишете отговорите на свободен текст, скриптът може тихо да „подобри“ правописа ви с някоя и друга фатална грешка, за да ви създаде излишна паника.

# 🗂️ Структура на проекта

├── index.html       # Основен интерфейс (карти, въпроси, капчи, плейър)
├── style.css        # Ретро стилове в стил тетрадка с карирани линии и Comic Sans
├── script.js        # Цялата логика на играта, таймери, анти-чийт и анимации
├── db.js            # База данни с въпроси по Математика и БЕЛ (за отваряне директно без локален сървър)
└── chalga.mp3       # Музикален файл за наказателния режим с плейъра


# 🚀 Инсталация и Стартиране

Тъй като проектът е изграден с чист HTML, CSS и JavaScript, не изисква сложна инсталация или npm пакети.
Клонирайте репозиторието или изтеглете файла:

git clone https://github.com/IvailoKanev09/nvo-parody.git

Уверете се, че следните файлове са в една и съща папка:

index.html
style.css
script.js
db.js
chalga.mp3 (задължително за пълното изживяване на наказателния режим)

Отворете index.html директно в браузъра си или стартирайте локален уеб сървър, за да избегнете проблеми с CORS заявките към db.js.

#💡 Технологичен стек

HTML5 & CSS3 (с използване на CSS анимации и гридове).
Vanilla JavaScript (ES6+) без външни библиотеки и фреймуъркове.
Web Audio API за генериране на аудио сигнали в аудио капчите.
